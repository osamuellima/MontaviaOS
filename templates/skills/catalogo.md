# Catálogo de skills

Referência de skills nativas do Claude Code que já resolvem tarefa comum, pra consultar antes
de criar algo novo com `/mapear-rotinas`. Se a tarefa já tem cobertura nativa, ativar essa em
vez de duplicar.

---

## Interface e página web

**Design de frontend** — gera interface web completa (HTML/CSS/React) com visual cuidado, sem
cair no genérico. Bom pra landing page, painel, componente, página de produto.

## Arte e peça visual

**Design em canvas** — gera arte visual (PNG/PDF) a partir de princípio de composição. Bom pra
capa, banner, peça avulsa, thumbnail.

## Documento

**PDF** — extrai texto/tabela, cria, junta/separa, preenche formulário.
**DOCX** — cria e edita Word com formatação, alteração rastreada e comentário — bom pra
proposta formal e documento que o cliente pede em Word.
**PPTX** — cria e edita apresentação com layout e nota de apresentador.
**XLSX** — cria e edita planilha com fórmula, formatação e gráfico.

## Escrita de documento/spec

**Coescrita de documento** — fluxo guiado que entrevista, itera rascunho e valida se o texto
funciona pro leitor. Bom pra proposta técnica, spec, documento de decisão.

## Teste de site/app

**Teste de webapp** — testa aplicação local via automação de navegador: print, verificação de
funcionalidade, leitura de log do navegador. Bom pra validar antes de publicar.

## Criar skill nova

**Criador de skill** — guia estruturado pra construir skill do zero quando `/mapear-rotinas`
não cobre o caso.

---

## Como adicionar skill nova a esse catálogo

```markdown
### Nome da skill
O que faz: [uma frase]
Bom pra: [caso de uso concreto]
Como ativar: [comando]
Origem: [nativa do Claude Code / criada nesse workspace / de terceiro]
```
